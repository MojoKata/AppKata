# AppKata

A FOSS app store built on git. Apps come from **Sources** (git projects you trust yourself)
and from **Trusts**: reviewers' `AppKata.md` files, accepted only when their changes are
signed by the Trust's Authorities. AppKata installs and updates apps from the projects'
own releases (GitHub, GitLab, Forgejo/Gitea), and you can publish your own reviews from a
git repository.

- Requirements: [`docs/requirements.md`](docs/requirements.md) (decisions in [`docs/gaps.md`](docs/gaps.md))
- Building and releasing: [`docs/build.md`](docs/build.md); CI and the signed release:
  [`docs/github-workflows.md`](docs/github-workflows.md); how the repository and its release key were
  set up: [`GENESIS.md`](GENESIS.md)
- Mockups and real screenshots: [`screenshots/`](screenshots/README.md)
- A published trust file of 43 FOSS apps: [`docs/AppKata.md`](docs/AppKata.md) (generated by `scripts/make_appkata_md.py`)
- License: GPL-3.0-or-later ([`LICENSE`](LICENSE), the GNU GPL version 3 text). The AppImage and the
  Windows installer carry it as `LICENSE.txt`, beside `THIRD-PARTY-NOTICES.txt`: the licenses of the
  parts they carry that others made, Python and Qt among them ([`docs/build.md`](docs/build.md#license-files))

## Run from source (development)

For development only; AppKata is installed from its AppImage (requirement 1.6). It runs on the
Python its release carries (`packaging/versions.env`), which `scripts/python-standalone.sh` fetches:

Its PySide6 needs glibc 2.34 or newer; on an older machine (RHEL 8), `scripts/test-tier1.sh` runs
the tests in a container instead.

```sh
"$(scripts/python-standalone.sh)" -m venv .venv
.venv/bin/pip install -e . pytest
.venv/bin/appkata                    # or: .venv/bin/python -m appkata
.venv/bin/python -m pytest           # 92 tests (6 run only on Windows): core, trust signatures, installs, reviews, forges, audit, log, explore, Windows
```

Needs git 2.34+ and, for OpenPGP-signed Trusts, gpg.

## Try it with demo data

```sh
scripts/demo_data.py build build/demo     # signed demo Trusts, your AppKata.md, Sources (offline)
scripts/demo_data.py sync build/demo      # fetch the real apps from GitHub
scripts/demo_data.py finish build/demo    # some "installed" apps, a pin and a minimum age
APPKATA_DATA=build/demo XDG_DATA_HOME=build/demo/xdg .venv/bin/appkata
APPKATA_DATA=build/demo XDG_DATA_HOME=build/demo/xdg .venv/bin/appkata --tour screenshots/linux
```

The apps are real GitHub projects; the reviewers, their keys and "TurboShield VPN" are made up.
