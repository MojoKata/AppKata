# AppKata

A FOSS app store built on git. Apps come from **Sources** (git projects you trust yourself)
and from **Trusts**: reviewers' `AppKata.md` files, accepted only when their changes are
signed by the Trust's Authorities. AppKata installs and updates apps from the projects'
own releases (GitHub, GitLab, Forgejo/Gitea), and you can publish your own reviews from a
git repository.

[![The Apps view: updates first, AppKata itself among them, then every installed app by name](https://mojokata.github.io/AppKata/screenshots/latest/dark/A01-apps.png)](https://mojokata.github.io/AppKata/screenshots/)

Every screen, in both themes, is on the [screenshots page](https://mojokata.github.io/AppKata/screenshots/):
CI's tour of the real app on demo data, for `master` and for each release. The one above is the
newest release's, or `master`'s while there is none.

## Download

Each release is on the [releases page](https://github.com/MojoKata/AppKata/releases):

- **Linux** (x86_64; the distributions in [R1.1](docs/requirements/R1-platform-and-architecture.md)):
  `AppKata-<version>-x86_64.AppImage`. Make it executable and run it; on its first start it offers
  to install itself into your app menu, and from then on it updates itself. The AppImage is
  AppKata's only form on Linux: there is no Flatpak, `.deb` or `.rpm` (R1.6).
- **Windows 10 22H2** (x64): `AppKata-<version>-setup.exe`, which installs for you alone by
  default, without a UAC prompt.

Each release's AppImage is signed by AppKata's release key, `AppKata <app@mojokata.xyz>`, whose
fingerprint is

```
A5C4 FAB7 54C2 34D3 8C98  3D94 02E7 71CD 068A 1ABD
```

The public key is [`packaging/appkata-release-key.asc`](packaging/appkata-release-key.asc), also on
keys.openpgp.org. To check a download:

```sh
gpg --import appkata-release-key.asc
gpg --verify AppKata-<version>-x86_64.AppImage.asc AppKata-<version>-x86_64.AppImage
```

`gpg` must say "Good signature from "AppKata <app@mojokata.xyz>"" and give the fingerprint above as
the "Primary key fingerprint". Its warning that the key "is not certified with a trusted signature"
is expected: the fingerprint is the check. Windows' installer isn't signed yet; check it against its
`.sha256`.

## Where to start

- **Add a Source**: a git project whose releases you install from, by its URL (Sources, **Add source**).
- **Add a Trust**: a reviewer's `AppKata.md`, whose signed reviews fill the Catalog. This repository
  publishes one, [`docs/AppKata.md`](docs/AppKata.md): 43 FOSS apps (generated by
  `scripts/make_appkata_md.py`).
- **Review** an app: your reviews go to an `AppKata.md` of your own, committed signed and pushed
  ([R8](docs/requirements/R8-writing-reviews.md)), so others can add it as a Trust.
- **What AppKata does, screen by screen**: [`docs/requirements/`](docs/requirements/README.md), and
  each screen's purpose in [`screenshots/README.md`](screenshots/README.md).
- **Working on AppKata**: [`DEVELOP.md`](DEVELOP.md): what's built, running it from source, and
  trying it with the demo data.
