# R17.16. The Audit

R17.16. **The Audit** (R13) records every change of a sandbox level, grant or template, naming what was
added and removed ("Offline editor · customized: added ~/Notes (read-write)"; review 2, F11); the AppArmor
system setup, a Not now to it (R17.10), and its repair; and review-badge resolutions.
