The Microsoft Visual C++ runtime, by Microsoft Corporation: vcruntime140.dll, vcruntime140_1.dll,
msvcp140.dll, msvcp140_1.dll and msvcp140_2.dll, the C and C++ runtime libraries Python and Qt for
Windows are built against, which come with them. They are Microsoft's "Distributable Code", which
Microsoft lets programs built with its compilers carry; they are not under AppKata's license. The
conditions for them are those the Python section gives, under "Additional Conditions for this
Windows binary build".
